En resumen

audite-seu-claude es un pequeño programa en Python que lee la configuración de tu Claude Code (el archivo CLAUDE.md, las skills, las memorias, los plugins y los scripts) y señala las instrucciones escritas para modelos anteriores que ahora dificultan el uso de Claude Fable 5.2. Es para quienes usan Claude Code a diario y van a cambiar de modelo. Entrega un informe con gráficos y una lista de sugerencias; tú marcas las que apruebas y tu propio Claude aplica solo esas correcciones. Solo necesitas Python 3: no usa internet ni modifica tu configuración (solo guarda el informe donde le indiques).

Qué es

La herencia invisible, encontrada línea por línea

Anthropic publicó 10 puntos de atención para Fable 5.2. Sigue las instrucciones al pie de la letra, por lo que las reglas antiguas producen efectos distintos. El kit convierte esos 10 puntos en comprobaciones automáticas.

🔍 Encuentra lo que bloquea

Peticiones de razonamiento en el texto (pueden provocar un rechazo), «piensa menos», presupuesto de tokens, orden de delegar siempre, «nunca» sin motivo, estilo rígido, esfuerzo antiguo.

📊 Muestra el peso

Gráficos por punto, por archivo y el peso del texto que entra en cada sesión: CLAUDE.md, índice de memoria y descripciones de skills. También señala skills repetidas y memorias antiguas.

✅ Tú apruebas, Claude corrige

Marca las sugerencias y genera correcoes.md. Se convierte en la solicitud de corrección: un elemento cada vez, con una copia del original. Las reglas de seguridad nunca se borran.

Cómo funciona

Tres pasos, tú decides

El programa solo lee. Tú decides qué cambia; tu Claude edita únicamente lo que aprobaste.

varrer.py lo lee todo→ relatorio.html con gráficos→ marcas lo que apruebas→ correcoes.md→ «aplica el correcoes.md»→ vuelve a ejecutarlo y compara
Los 10 puntos de Anthropic

Qué dice la página oficial y qué comprueba el kit

Fuente: Prompting Claude Fable 5.2 (consultada el 11/11/2026). Las cifras proceden de las pruebas de la propia Anthropic.

1 Esfuerzo

El valor predeterminado de la API es high. Medium para el día a día; xhigh y max solo cuando hayas medido una mejora. «Responde sin pensar» no reduce el razonamiento: baja el esfuerzo. Comprueba: max fijo, xhigh predeterminado, ajuste copiado de un modelo antiguo, Fable 5.2 en low/medium.

2 Finalización anticipada

En tareas largas a veces se detiene antes de terminar, más a menudo en low y medium. El texto oficial redujo a la mitad las sesiones abandonadas a medias, con +~30% de tokens. Comprueba: si tu CLAUDE.md contiene este texto (está en blocos/terminar-tarefa.md).

3 Aprobaciones

Indica la acción («sí, ejecuta la migración en la base de datos de prueba») en vez de «continúa». La regla de aprobación debe nombrar las acciones. Comprueba: aprobación para «cualquier acción» y claude -p "continue" en un script.

4 Responsable del código

«Este código es tuyo» hace que reorganice el código: ~1,5x más tokens y cambios que nadie pidió. Úsalo solo cuando quieras eso y revisa el diff. Comprueba: la frase, como aviso.

5 Silencio

Trabaja en silencio durante secuencias largas. El texto oficial le pide hablar antes de usar la primera herramienta, con +~20% de tokens. Comprueba: si tienes este texto (blocos/avisar-progresso.md).

6 Subagentes

Si el prompt le ordena delegar, delega mucho. Revisa primero esas líneas. Comprueba: «usa siempre subagentes», «agent army», «delega todo».

7 Cautela acumulada

Las notas y las memorias acumulan «nunca» y obedece todas las órdenes. Borra las que ya no tengan motivo; añade alcance y motivo a las demás; enumera lo que NO necesita aprobación. Comprueba: «nunca» sin motivo, «nunca vuelvas a intentarlo», órdenes absolutas en mayúsculas, memorias antiguas.

8 Instrucciones antiguas

Elimina: el presupuesto de tokens en el prompt, «piensa menos», «trata la respuesta anterior como definitiva» (deja de señalar sus propios errores) y las reglas de estilo rígidas. Comprueba: las cuatro.

9 Informe final

Pídele que escriba para alguien que no haya visto el trabajo: primero lo principal, sin términos inventados. Comprueba: si tienes este texto (blocos/relatorio-claro.md).

10 Rechazos

Pedir que escriba su razonamiento en la respuesta puede activar el filtro reasoning_extraction y detener la skill. Comprueba: «muestra tu razonamiento paso a paso», «chain of thought» — gravedad alta.

Guía de uso · paso a paso

Desde clonar hasta corregir Claude

Es el orden que recomienda Anthropic: primero el esfuerzo, después limpiar las instrucciones y luego medir.

1

Descarga el kit

Una carpeta, un archivo principal.

git clone https://github.com/inematds/audite-seu-claude.git ~/audite-seu-claude
2

Pon Fable 5.2 en high para las tareas largas

El comando /effort de Claude Code cambia el nivel de esfuerzo (cuánto piensa el modelo). Úsalo antes de una tarea grande. En los bots con claude -p, pasa --effort high.

/effort high
3

Ejecuta la auditoría

Desde la carpeta del proyecto. --home también lee tu ~/.claude (CLAUDE.md global, skills, memorias, plugins).

cd ~/meu-projeto
python3 ~/audite-seu-claude/varrer.py . --home --html relatorio.html --saida-json relatorio.json
# en el terminal: total de hallazgos, por punto y por gravedad
4

Abre el informe y marca lo que apruebas

Cada sugerencia tiene un ID (A001, A002…). Filtra por capa — Fable 5.2 (las líneas que cambian el comportamiento del modelo) o volumen (peso del contexto, skills repetidas o sin uso, memorias antiguas) — o por gravedad. Haz clic en generar correcoes.md: el navegador descarga el archivo y muestra el texto en pantalla. Mueve el archivo a la carpeta del proyecto. También puedes generarlo directamente ahí desde el terminal, con los ID:

python3 ~/audite-seu-claude/varrer.py --correcoes A001,A004,A007 --de relatorio.json --saida correcoes.md
5

Pídele a tu Claude que aplique las correcciones

Con correcoes.md en la carpeta del proyecto (también sirve la ruta: «aplica el ~/Downloads/correcoes.md»). El encabezado del archivo ya indica cómo hacerlo: un elemento cada vez, copia del original en .audite-backup/, las reglas protegidas nunca se borran y los archivos de plugins no se editan. La aprobación solo cubre esas ediciones.

# en Claude Code, dentro de la carpeta del proyecto
aplica el correcoes.md
6

Vuelve a ejecutarla y compara

Los hallazgos aplicados desaparecen. Luego ejecuta tu tarea más larga y observa dónde se detiene, se queda en silencio o delega demasiado. Para cada síntoma, pega el bloque adecuado de blocos/, uno cada vez.

python3 ~/audite-seu-claude/varrer.py . --home
cat ~/audite-seu-claude/blocos/terminar-tarefa.md # si se detiene a mitad
7

Opcional: la skill y el CI

La skill realiza los pasos 3 a 6 mediante Claude Code. --uso 30 lee los registros de tus sesiones (~/.claude/projects/*.jsonl, locales) y marca las skills que no hayas usado en 30 días. --estrito hace fallar el CI si hay algún hallazgo de gravedad alta.

cp -r ~/audite-seu-claude/skill/audite-seu-claude ~/.claude/skills/
python3 ~/audite-seu-claude/varrer.py . --home --uso 30
python3 ~/audite-seu-claude/varrer.py . --estrito  # sale con 1 si hay algo de gravedad "alta"
Ejemplos

El informe de un proyecto de prueba

Generado a partir de tests/fixtures/sujo, un proyecto creado deliberadamente con una línea de cada tipo (24 hallazgos). Abre el informe interactivo (en portugués) y prueba el botón para generar correcoes.md.

En una máquina de producción con 148 skills cargadas, la primera auditoría tardó 4 segundos y encontró: un hook de plugin que ordena escribir «telegráfico, en fragmentos» (punto 8), una skill de plugin con «si hay un 1% de probabilidad, estás obligado» (punto 7), nueve órdenes de delegar siempre (punto 6) y Fable 5.2 configurado en medium (punto 1).

Cuidados y próximos pasos

El auditor señala; tú decides

La propia Anthropic dice que no es necesario eliminar todas las instrucciones antiguas. Prueba cada cambio en una tarea real.

Protegida
La regla de seguridad se conservaLos «nunca» relacionados con API, crédito, borrar, publicar o contraseñas aparecen como protegidos: la sugerencia es darles alcance y motivo, nunca borrarlos.
Plugin
No edites archivos de pluginsLa actualización deshace el cambio. Escribe en el CLAUDE.md global que esa regla no se aplica o desactiva el plugin.
Costo
Los bloques cuestan tokensTerminar la tarea: +~30% de salida. Avisar del progreso: +~20%. Pégalos solo si observas el síntoma.
